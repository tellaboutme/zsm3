# Security policy

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/tellaboutme/zsm3/security/advisories/new). Do not open public issues for security problems.

You will receive an answer within 5 working days. Reports concerning personal data of students are treated as incidents under the GDPR and escalated to the school's data protection officer.

Only the latest version on the `main` branch is supported.

## Polityka bezpieczeństwa

Podatności prosimy zgłaszać poufnie przez [GitHub security advisories](https://github.com/tellaboutme/zsm3/security/advisories/new), a nie w publicznych zgłoszeniach.

Odpowiedź otrzymasz w ciągu 5 dni roboczych. Zgłoszenia dotyczące danych osobowych uczniów są traktowane jako incydenty w rozumieniu RODO i przekazywane Inspektorowi Ochrony Danych szkoły.

Wsparciem objęta jest wyłącznie najnowsza wersja z gałęzi `main`.
