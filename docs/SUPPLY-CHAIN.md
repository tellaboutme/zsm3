# Цепочка поставок: политика и исключения

## Политика

| Механизм                         | Где                      | Что делает                                                                                             |
| -------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------ |
| `minimumReleaseAge: 10080`       | `pnpm-workspace.yaml`    | ставит только версии старше 7 дней; большинство захватов пакетов обнаруживают за 1–3 дня               |
| `exclude-newer = "7 days"`       | `tools/pyproject.toml`   | то же для Python                                                                                       |
| `cooldown: 7`                    | `.github/dependabot.yml` | Dependabot не предлагает версии моложе 7 дней                                                          |
| `trustPolicy: no-downgrade`      | `pnpm-workspace.yaml`    | отказывает, если новая версия опубликована «слабее» прежней (без provenance после версий с provenance) |
| `allowBuilds`                    | `pnpm-workspace.yaml`    | install-скрипты запускаются только у явно разрешённых пакетов                                          |
| `blockExoticSubdeps`             | `pnpm-workspace.yaml`    | транзитивные зависимости только из реестра, не из git/URL                                              |
| Actions по SHA, образы по digest | `.github/`               | тег нельзя тихо перенаправить; zizmor требует `hash-pin` для всех                                      |
| `pnpm audit`, OSV-Scanner        | CI                       | любая известная уязвимость любого уровня останавливает сборку                                          |

Исключение из политики допустимо только с записью в таблицу ниже: что, почему, кто проверил, когда пересмотреть.

## Исключения

### `minimumReleaseAgeExclude`

| Пакет                         | Причина                                                                                                                                                                     | Проверено  | Пересмотр                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ----------------------------------------------------------- |
| `vitest` и `@vitest/*` 4.1.12 | исправляет GHSA в `@vitest/mocker` (внедрение кода через mock, обход пути на Windows); вышла за 6 дней до установки; все пакеты опубликованы через GitHub OIDC с provenance | 2026-10-21 | удалить после 2026-10-22, когда версия станет старше 7 дней |

### `trustPolicyExclude`

| Пакет                        | Причина                                                                                                       | Проверено  |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------- | ---------- |
| `semver@6.3.1`               | выпущена командой npm (lukekarrys) в 2023 году, до появления provenance; новые ветки публикуются с provenance | 2026-10-21 |
| `chokidar@4.0.3`             | выпущена автором (paulmillr) в 2024 году до перехода на OIDC; 5.x уже с provenance                            | 2026-10-21 |
| `chromium-bidi@157.0.8090-0` | официальный аккаунт Google `chrome-devtools-npm`; требуется puppeteer-core 25 для Lighthouse 13               | 2026-10-21 |

Из-за той же политики выбраны не самые новые версии:

- `lefthook` 2.2.1 вместо 2.2.2: 2.2.2 опубликована вручную без OIDC;
- `@cloudflare/vitest-pool-workers` 0.22.0 вместо 0.23.0: 0.23.0 опубликована без provenance. Поэтому `compatibility_date` Worker'а — `2026-08-15`, последняя дата, которую поддерживает workerd этой версии.

### Уязвимости без исправления

| Advisory            | Пакет                                         | Почему не эксплуатируется                                                                                                | Где записано                                  | Пересмотр                             |
| ------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------- | ------------------------------------- |
| GHSA-vfj7-8cjw-p6xm | `braces` 3.0.3 (через stylelint → micromatch) | переполнение стека на вложенных шаблонах от атакующего; stylelint получает только фиксированные glob'ы из `package.json` | `auditConfig.ignoreGhsas`, `osv-scanner.toml` | 2027-01-21 или при выходе исправления |

### `overrides`

`qs`, `sharp`, `undici` подняты до исправленных версий (все старше 7 дней): их тянут Stryker и wrangler/miniflare.

## Известные ограничения сканеров

- **OSV-Scanner** читает только первый YAML-документ `pnpm-lock.yaml` pnpm 12 (15 служебных пакетов). `.github/scripts/osv-scan.sh` выделяет последний документ (~1000 пакетов) и падает, если в нём нет `importers:`.
- **actionlint** 1.7.12 не знает синтаксис `uses: $/...` (GitHub, июль 2026). Подавлено одно сообщение для `$/.github/actions/setup`; закрепление остальных actions проверяет zizmor.
- **Semgrep** правило `github-actions-mutable-action-tag` считает `$/...` изменяемым тегом. Правило отключено, ту же проверку надёжнее делает zizmor `hash-pin`.
